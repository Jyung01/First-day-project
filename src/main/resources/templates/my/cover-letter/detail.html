연결 공고: 첫출근테크 백엔드 개발자 채용

지원 동기

사용자의 문제를 안정적인 서비스로 해결하는 백엔드 개발자가 되고 싶어 지원했습니다. 교육 과정과 팀 프로젝트에서 요청부터 DB 저장까지 데이터 흐름을 직접 점검하며 구현 경험을 쌓았습니다.

성장 과정

문제가 생기면 결과만 고치기보다 로그와 요청 값을 따라가며 원인을 확인하는 습관을 길렀습니다. 해결한 내용은 다시 같은 문제가 반복되지 않도록 서로 정리하고 팀원과 공유했습니다.

직무 역량

Spring Boot, MyBatis, MySQL을 활용한 CRUD와 주문·지원 흐름을 구현했고, Spring Security 기반 인증과 AWS EC2 배포 과정을 경험했습니다.

협업 경험

팀장으로서 기능 단위를 나누고 Git 브랜치·PR 흐름을 관리했습니다. 막히는 부분은 함께 원인을 확인하고, 경긴한 구조는 문서로 남겨 작업 기준을 맞췄습니다.

입사 후 포부

팀의 코드 기준과 업무 흐름을 빠르게 익히고, 피드백을 같은 실수로 반복되지 않는 개발자가 되겠습니다. 기능 구현뿐 아니라 운영 과정의 원인 분석과 기록에도 책임감을 갖겠습니다.
