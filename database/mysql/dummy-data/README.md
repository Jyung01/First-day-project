# MySQL 더미데이터

기준 데이터와 시연용 데이터를 저장하는 폴더다.

권장 파일 구분:
- `reference_data.sql`: 직무·기술·FAQ·문의 카테고리 등 서비스 필수 기준값
- `dummy_data.sql`: 회원, 기업, 공고, 지원, 후기 등 시연용 데이터

이후 추가되는 INSERT문은 최신 DDL의 컬럼과 제약조건에 맞춰 관리한다.

## 현재 보관 중인 것

- `firstday_dummy_data_v1/`: V1 시점에 작성한 **참고용 스냅샷**. 현재 스키마에서는 실행되지 않는다.
  어떤 계정·상태 조합(승인대기·반려·이용정지·탈퇴 등)을 테스트용으로 설계했는지 참고하는 용도다.
  실행 불가 지점은 해당 폴더 README 참고.

## 관리 규칙

- 더미데이터는 마이그레이션과 성격이 다르다. 마이그레이션은 이력이라 수정하지 않고 새 번호로 쌓지만,
  **더미는 현재 상태의 재현이라 최신본 한 벌만 두고 직접 고친다.** 과거 버전은 git 히스토리로 충분하다.
- 스키마를 바꾸는 마이그레이션을 추가하면 같은 PR에서 더미데이터도 함께 갱신한다.
  이 규칙이 없으면 위 v1처럼 조용히 어긋난다.
- 실제 DB 덤프는 회원 이메일·전화번호 등 개인정보가 들어가므로 저장소에 커밋하지 않는다.
